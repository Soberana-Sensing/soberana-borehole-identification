# Data

Folder layout follows the Soberana convention. Contents are git-ignored; the folders and these
READMEs are tracked so the layout survives a clone.

- `raw/` — data as delivered. Never edited in place.
- `interim/` — reshaped intermediates.
- `derived/` — analysis outputs.

Every dataset referenced in a document carries its date: acquisition window, product epoch, or
retrieval date.
