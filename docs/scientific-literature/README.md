# Scientific literature

Papers for this project. PDFs stay local and are git-ignored; extracted text lives in `.extracted/`
when the set exists.

Read papers as text, never as an uploaded PDF:

```bash
~/.config/opencode/tools/pdftext.py docs/scientific-literature/<paper>.pdf
```

A router mapping questions to papers goes here once the set is large enough to need one.

Empty as of 2026-11-17.
